FORMULAIRE DE CONTACT AUDACE — RELAIS RESEND SUR RAILWAY

Déjà en place :
  - Projet Railway « audace-contact », service « relais-formulaire » (fonction Bun, code : relais.ts)
  - Adresse : https://relais-formulaire-production.up.railway.app
  - Domaines acceptés : audace-chavenay.fr (officiel) et audace-chavenay.org (test, objet préfixé [TEST])
  - Variables : CONTACT_TO = contact@audace-chavenay.fr
                MAIL_FROM  = Site AUDACE <site@audace-chavenay.fr>
  - Le site (index.html) pointe déjà vers ce relais.
  - Tant que la clé Resend n'est pas saisie, le relais répond « indisponible »
    et le formulaire bascule automatiquement sur la messagerie du visiteur.

Reste à faire :
1. RESEND
   - Domains > Add domain > audace-chavenay.fr
   - Ajouter TELS QUELS dans la zone DNS OVH les enregistrements affichés par Resend
     (DKIM, et MX + SPF du sous-domaine d'envoi). Ne pas toucher aux MX principaux.
   - Attendre « Verified ».
   - API Keys > Create > permission « Sending access », domaine audace-chavenay.fr.
2. RAILWAY
   - Projet audace-contact > relais-formulaire > Variables > New Variable
     RESEND_API_KEY = la clé Resend (le service redémarre tout seul).
3. TEST
   - Envoyer un message depuis https://www.audace-chavenay.org (arrive avec [TEST])
   - En cas d'échec : Railway > relais-formulaire > Logs (affiche la réponse de Resend).
